# atividade-git
Engenharia de Software - Atividade prática (Git/GitHub): criando um projeto e fazendo commits

Para concluir esta atividade, os seguintes passos foram executados:

1. **Criação do Repositório:** O repositório foi criado diretamente na plataforma do GitHub.
2. **Clone Local:** O repositório foi clonado para o ambiente de desenvolvimento local.
3. **Desenvolvimento e Commits:** Foram criados arquivos simulando um projeto front-end básico, gerando os 3 commits exigidos na atividade:
   - `feat: estrutura inicial do arquivo index.html`
   - `feat: adiciona estilos`
   - `docs: README atualizado com a descrição do projeto`
4. **Push:** As alterações locais foram enviadas para o repositório remoto no GitHub.
